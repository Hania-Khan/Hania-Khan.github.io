# Hania Khan · Portfolio

Personal portfolio site for Hania Khan, Software Engineer and Solutions Architect.

Live at **https://hania-khan.github.io/**

## Structure

```
index.html            main page
404.html              not-found page
Hania_Khan_CV.pdf     downloadable CV
assets/css/style.css  styles (light and dark themes)
assets/js/main.js     screenshot viewer, copy button, theme toggle
assets/img/           screenshots
assets/favicon.svg    browser tab icon
assets/og-image.png   preview image shown when the link is shared
.nojekyll             tells GitHub Pages to serve files as-is
```

## Editing

Plain HTML, CSS and JavaScript with no build step. Edit a file, commit, and GitHub Pages republishes within a minute or two.

- Update the CV: replace `Hania_Khan_CV.pdf`, keeping the same file name.
- Add a screenshot: put the image in `assets/img/` and copy one of the existing `<div><button class="shot">…</button></div>` blocks in `index.html`.

Product images of JazzCash and UpStart Commerce come from their public app-store listing and website and belong to their owners.
